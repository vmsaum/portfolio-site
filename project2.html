Project 2 - Wine Quality Analysis & Prediction

This project focused on analyzing wine quality using physicochemical properties such as alcohol content, acidity, sulfur dioxide levels, sugar content, pH, and density. The goal was to identify which chemical characteristics influence wine quality and determine whether machine learning models could accurately predict quality ratings.

The project was completed as part of a collaborative data science team. My role involved data wrangling, where I helped clean and prepare the dataset for analysis. This included handling missing values, checking for inconsistencies, organizing the data, and preparing it for machine learning and visualization.

Project Objectives

  • Analyze factors that influence wine quality
  • Compare characteristics between red and white wine
  • Prepare data for machine learning analysis
  • Identify relationships between chemical properties and quality ratings

Tools & Technologies Used

  • Python
  • Google Colab
  • Pandas
  • Scikit-Learn
  • GitHub
  • PowerPoint

Key Findings

The analysis showed that alcohol content was one of the strongest predictors of wine quality, while volatile acidity had a negative impact on quality ratings. The machine learning models identified meaningful relationships between chemical properties and overall wine quality, helping explain which factors contribute most to higher quality scores.
